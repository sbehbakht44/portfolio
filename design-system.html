Casing, tracking & size

Sentence case throughout. All-caps is not part of this system.

  • Sentence case everywhere: navigation, eyebrows, labels, buttons, back links, footers.
  • No text-transform: uppercase anywhere in the stylesheets.
  • Tracking stays tight: letter-spacing: .01em on small type; the wide tracking that caps needed is gone.
  • Labels earn attention by weight and opacity, not by shouting; never by shrinking.
  • 16px is the floor. No text on the site, anywhere (labels, tags, captions, footnotes) renders smaller than 16px.

Headings and body copy are both set in #370000: body copy at 78% opacity, muted text at 60%, faint captions and footers at 45%. Anything clickable (nav, buttons, back links, arrows) uses #211d24 instead, so it reads as distinctly interactive rather than as reading copy. Hairlines use #e1d9c9.

Tags

Every case study is tagged from one fixed vocabulary of four: no freeform labels, so the set stays scannable across the whole site.

DesignHealthcareEducationResearch

White pill, 1px line border, Work Sans 500 at 16px. A project can carry more than one tag: Design and Research apply to nearly everything Sara ships; Healthcare and Education mark the domain. Tags live on the project header only: the home page list stays untagged.

Header images

The image at the top of every case study is a plain rectangle, not a floating card.

  • No caption. The image speaks for itself. No credit line laid over it.
  • No card frame. Square corners, no drop shadow; it isn’t a boxed-in photo, it’s the page itself.
  • Aligned to the content margin, not the outer page edge: same left/right line as the title, the body copy, and everything below it.

How to keep it

Every page carries an identical DESIGN SYSTEM block at the end of its <style> element. It is the last thing the browser reads, so it wins.

  • Edit the block, not the page. Change it in one file, paste the same block into the other seven.
  • New page? Copy the block in and the page inherits the whole system.
  • New component? Reuse .btn, .link-arrow, .arrow-glyph and the tokens rather than writing fresh values.
  • Never add a third body/display typeface, an all-caps rule, a new arrow style, or a hard-coded hex that isn’t a token.
